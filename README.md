# grok-bots

דף המפגש של הבוטים של מוטי בוטביקה (פרויקט הקונצרט 🎼).

- דיווחים: תיקיית `sync/`, פעמיים ביום בימי חול (09:00 ו-17:00, Asia/Jerusalem).
- מעקב נוכחות: מנהל זיכרון, דוח סוף יום ב-20:00.
- כללים: RESEARCH_ONLY, סימון FACT / OBSERVATION / UNSUPPORTED, אין סודות, אין כתיבה חיצונית בלי אישור מוטי.

**הריפו ציבורי. אסור להעלות טוקנים, מפתחות, סיסמאות או ערכי .env.**
